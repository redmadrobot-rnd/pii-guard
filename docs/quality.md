# Качество

Замер на четырёх открытых наборах, один из них наш. Рядом — открытые решения на
тех же текстах и тем же скорером
([`tests/quality/paper_score.py`](../tests/quality/paper_score.py)).

| Набор | Текстов | Типов |
|---|---|---|
| [`hivetrace/pii-bench`](https://huggingface.co/datasets/hivetrace/pii-bench) | 1810 | 13 |
| [`alexen2/pii-ner-ru-benchmark`](https://huggingface.co/datasets/alexen2/pii-ner-ru-benchmark) | 1000 | 3 |
| [`alrosait/pii-synthetic-ru`](https://huggingface.co/datasets/alrosait/pii-synthetic-ru) | 4500 | 2 |
| [`redmadrobot-rnd/pii_benchmark`](https://huggingface.co/datasets/redmadrobot-rnd/pii_benchmark) | 2841 | 21 |

Два правила зачёта, тип проверяется в обоих, сопоставление один к одному:
**строгое** — начало, конец и тип совпали точно; **по типу** — тип совпал, спаны
пересеклись хотя бы на символ.

## Рядом с другими решениями

Область — пересечение того, что умеют все участники: имя, адрес, почта, телефон,
паспорт, банковская карта. Ячейка — `строгая / по типу`.

| Система | hivetrace entity | hivetrace domain | alexen2 | alrosait | наш бенчмарк |
|---|---|---|---|---|---|
| [**`redmadrobot-rnd/pii-guard`**](https://github.com/redmadrobot-rnd/pii-guard) | **88.6 / 93.7** | **94.8 / 97.5** | **25.5 / 98.5** | **78.3 / 89.4** | **90.3 / 95.0** |
| [`cloud-ru-tech/guardrails-llm-filter`](https://github.com/cloud-ru-tech/guardrails-llm-filter) | 71.4 / 86.0 | 89.0 / 94.9 | 18.3 / 89.8 | 52.6 / 76.5 | 14.2 / 30.5 |
| [`hivetrace/gliner-guard-omni`](https://huggingface.co/hivetrace/gliner-guard-omni) | 82.8 / 88.6 | 82.5 / 92.0 | 24.6 / 95.9 | 49.9 / 84.6 | 58.7 / 73.2 |
| [`hivetrace/gliner-guard-uniencoder`](https://huggingface.co/hivetrace/gliner-guard-uniencoder) | 56.9 / 65.1 | 71.5 / 80.3 | 24.1 / 88.9 | 48.5 / 82.0 | 50.6 / 64.6 |

Голая ветка правил, без модели, на нашем бенчмарке даёт 49.0 против 48.9 у
`guardrails-llm-filter` — правила против правил идут вровень, весь остальной
отрыв приносит модель. Обратное тоже верно: модель без правил даёт 44.3 против
66.8 у связки в их общей области, и вдобавок не умеет четыре типа и не проверяет
контрольные суммы.

## Как читать

- **Низкая строгая на alexen2 — свойство разметки**, там в спан входит концевая
  точка, а нормализацию границ протокол запрещает. Реальный результат — 98.1.
- **Наборы спорят о границах.** Паспорт в hivetrace размечен вместе со словами
  («серия 7518, номер 492137»), у нас — только данные. Совпасть с обоими
  соглашениями нельзя, поэтому абсолютные значения строгой метрики читать не
  стоит — только сравнение систем на одном наборе.
- **Метрика «любое пересечение» не публикуется**: её выигрывает система, которая
  замажет текст целиком. Она осталась в регресс-гейте, где вопрос — «стало ли
  хуже, чем вчера».

Гейт на своём наборе, с порогами и сравнением против базовой линии, описан в
[`tests/quality/README.md`](../tests/quality/README.md).
