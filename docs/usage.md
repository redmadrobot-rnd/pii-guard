## Веса

Скачивать вручную не нужно. По умолчанию берётся
[`redmadrobot-rnd/rubert-base-pii-ner`](https://huggingface.co/redmadrobot-rnd/rubert-base-pii-ner)
(дообучен из `ai-forever/ruBert-base`, Apache-2.0) — в образ они запечены на
сборке, при установке пакетом качаются при первом вызове.

| Сценарий | Что делать |
|---|---|
`docker run` | ничего, веса в образе |
`pip install ".[ner]"` | ничего, скачается при первом вызове (~700 МБ) |
закрытый контур | `huggingface-cli download redmadrobot-rnd/rubert-base-pii-ner`, затем `PII_GUARD_NER_MODEL=/path` |
своя модель | `PII_GUARD_NER_MODEL=<repo id или путь>` |

Формат совместимой замены: token-classification, BIO-разметка, 21 тип —
см. `NER_ENTITY_MAPPING` в `src/pii_guard/engine.py` и карточку модели.

## Смещения указывают на `normalized_text`

`entities[].start/end` относятся к `normalized_text`, **а не к присланному
тексту**. Нормализация и препроцессор английских числительных меняют длину;
транслит-проход переносит спаны обратно, а base64-блоб сворачивается в свои
границы. Резать нужно `normalized_text`.

## Составной номер документа — две сущности

`паспорт серия 7518, номер 492137` возвращается двумя спанами, `7518` и `492137`,
а не одним на всю фразу. Служебные слова в спан не входят: маска ложится на
`паспорт серия ****, номер ******`, в режиме тега появляются два плейсхолдера, и
в таблице псевдонимов будет две записи. Это относится к паспорту, правам,
военному билету и свидетельству о рождении — всему, что записывается парой
«серия + номер».

Препроцессоры существуют, потому что ПДн приходят обфусцированными: `menya
zovut Ivan Petrov` (транслит), `семь девять один шесть` (числительные словами),
base64-блоб внутри текста. Все три включены по умолчанию и отключаются
по отдельности.

## Настройка

Приоритет: аргумент → `PII_GUARD_*` → `config.yaml` → значение по умолчанию.

| Переменная | Смысл |
|---|---|
`PII_GUARD_NER_MODEL` | repo id на HF или локальный путь |
`PII_GUARD_NER_REVISION` | commit sha; без пина поведение может измениться при перезаливке модели |
`PII_GUARD_NER_DISABLED` | `1` → только правила |
`PII_GUARD_DEVICE` | `auto` (дефолт) \| `cpu` \| `cuda` \| `mps` |
`PII_GUARD_ENTITIES` | список типов через запятую |
`PII_GUARD_MAX_TEXT_CHARS` / `PII_GUARD_MAX_TEXTS` | лимиты запроса |
`PII_GUARD_API_KEYS` | ключи через запятую; **не задано → авторизации нет** |
`PII_GUARD_HOST` / `PII_GUARD_PORT` | адрес `pii-guard-server`; по умолчанию `127.0.0.1:8080` |
`PII_GUARD_NER_SCORE` | скор, который получают спаны от модели (по умолчанию `0.70`) |

`auto` выбирает CUDA при наличии GPU, иначе CPU. Apple `mps` автоматически
не берётся — чтобы прогон на macOS оставался численно сравним с Linux.

## Развёртывание

`pii-guard-server` слушает `127.0.0.1:8080`; чтобы выставить наружу, нужно
явно задать `PII_GUARD_HOST=0.0.0.0`. Контейнер слушает `0.0.0.0` внутри себя,
границей служит публикуемый порт — в примерах он привязан к loopback.

Наружу без прокси не выставлять: ручка принимает произвольный текст и тратит CPU
на каждый запрос.

Авторизация опциональна и выключена по умолчанию — дефолтного ключа нет
намеренно, заглушка, которую никто не меняет, хуже отсутствия защиты. Что
реально ограничивает нагрузку: `PII_GUARD_MAX_TEXT_CHARS`, `PII_GUARD_MAX_TEXTS`
и семафор на инференс (модель обслуживает один запрос за раз, при перегрузке
приходит `503`). Пропускная способность наращивается репликами, не потоками.

Оба лимита проверяются уже после того, как тело запроса прочитано и разобрано,
то есть память под него выделяется до проверки. Ограничение размера тела —
задача прокси перед сервисом (`client_max_body_size` в nginx и аналоги).

Латентность: BERT-base на CPU — десятки-сотни мс. Против regex-фильтра это
много, против вызова LLM в 2-5 секунд — единицы процентов.

## Разработка

```bash
python -m venv .venv && . .venv/bin/activate
pip install -e ".[ner,server,dev]"
python -m spacy download ru_core_news_sm

pytest tests/unit          # быстро, без весов и без torch
pytest -m quality          # quality-gate: нужны веса и датасеты
ruff check . --fix
```

Юнит-тесты специально не зависят ни от torch, ни от spaCy, ни от весов —
клонировал, поставил, получил зелёный прогон за секунды. Presidio при
отсутствии подменяется минимальным стабом (`tests/conftest.py`).
